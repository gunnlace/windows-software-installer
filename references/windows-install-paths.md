# Windows 安装路径、空间与权限

在用户选择路径前，先让其打开“文件资源管理器 → 此电脑”，确认目标盘确实存在、可用空间充足且不是网络驱动器或临时介质。不要仅因盘符为 D 就假设适合安装。

| 内容 | 推荐位置 | 决策理由 |
| --- | --- | --- |
| 普通系统级办公软件 | 安装器默认位置，通常是 `C:\Program Files\厂商\软件名` | 兼容性和更新机制通常最佳。 |
| 大型专业软件程序 | 确认空间和权限后使用非系统盘，例如 `D:\Apps\厂商\软件名` | 减少系统盘占用；路径仍保持稳定。 |
| 项目、样例、素材、仿真结果 | 独立数据目录，例如 `D:\SimulationData\项目名` | 方便备份、迁移和清理，不与程序混杂。 |
| 用户配置、缓存、许可证服务 | 厂商默认位置 | 这些组件常依赖固定位置或权限，随意移动容易损坏更新与授权。 |

不要建议安装到 `C:\` 或 `D:\` 根目录、桌面、下载文件夹、`Windows` 目录，或看似方便但会被同步/清理的临时位置。避免在路径中使用模糊名称和特殊字符；不要为了安装某一软件建立多层难懂目录。

空间评估应同时考虑安装包、解压/临时文件、程序本身、更新余量和数据目录。厂商没有明确数字时，不应声称具体的空间需求；让用户查看官方系统要求或安装器估算。专业软件的项目、结果与缓存可能远大于程序本身，须单独留余量。

如果目标路径被拒绝访问，先确认当前用户权限及该目录是否受组织策略保护。不要建议取得所有权、关闭受控文件夹访问或修改系统 ACL 来强行继续；优先选择安装器默认位置、已获授权的位置，或向 IT 求助。
