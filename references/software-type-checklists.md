# 软件类型检查表

## 办公软件

- 确认账号登录、订阅或永久许可证是否匹配用户拥有的授权。
- 检查文件格式兼容性；若会接管默认文件关联或浏览器，说明可逆影响并征得确认。
- 用户有旧模板、词典、宏或插件时，先建议备份用户数据；不要自动迁移未知宏。
- 安装成功后，仅按用户需要验证打印、云盘同步或团队功能。

## 专业仿真与工程软件

- 核对厂商公布的最低/推荐 CPU 指令集、内存、显卡驱动、程序空间及临时空间。
- 确认软件与项目文件、插件、求解器和运行库的版本矩阵，避免盲目覆盖旧版本。
- 识别单机、浮动、网络或离线许可证；服务器地址、端口和激活限制不清楚时先向许可证管理员确认。
- 主程序、求解器、材料库、示例、文档及许可证管理器按用途选择，不默认全选。
- 将大型项目、结果和缓存设置到可配置的数据盘目录，前提是厂商允许；不要擅自移动内部配置路径。
- 完成后运行官方小型样例，检查许可证和必要的加速功能，再处理生产任务。

## ZIP/便携版

- 只使用厂商明确提供的便携版或压缩包；检查压缩包的来源和校验信息。
- 解压到规划目录，不要在下载目录或压缩包预览窗口内直接运行。
- 解压前先对 ZIP 本身"解除锁定"，否则解压出的文件会逐个带上来源标记，导致程序启动报错；步骤见 [来源、签名与 SmartScreen](source-and-signature.md)。
- 先读官方 README，确认是否需要运行库、首次配置或专用卸载方式。
- 用户询问更新或删除时，先确认数据、配置和许可证文件的实际位置。

## ISO 与离线安装包

- 确认镜像来源、发布者、哈希及版本，再在 Windows 中挂载。
- 只运行厂商说明指定的安装入口；不执行未知批处理或自动脚本。
- 安装完成并验证后，可按需卸载镜像；是否删除离线包由用户的重装需求决定。
